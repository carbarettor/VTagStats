# VTagStats

## Описание
**VTagStats** — это десктопное приложение на Python с использованием графической библиотеки Tkinter. Оно функционирует как интерактивная справочная система и учебное пособие, предоставляющее быстрый доступ к примерам и объяснениям по ключевым модулям и базовым операциям в Python.

## Архитектура и интерфейс
* **Графический интерфейс (GUI):** Реализован на Tkinter, что обеспечивает кроссплатформенность (Windows, Linux, macOS).
* **Одностраничный интерфейс:** Основное окно разделено на две панели — область отображения информации и боковая панель с кнопками навигации.
* **ScrolledText Widget:** Используется для удобного просмотра больших объемов текста с прокруткой.

## Возможности
* Быстрый поиск и навигация по темам Python.
* Понятное структурирование справочных материалов.
* Легковесность и запуск без установки тяжелых зависимостей.
